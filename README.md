# 🚛 StrongLogistics — Система управління та оптимізації логістичних маршрутів

[![Python](https://img.shields.io/badge/Python-3.10+-blue?logo=python)](https://python.org)
[![FastAPI](https://img.shields.io/badge/FastAPI-0.100+-green?logo=fastapi)](https://fastapi.tiangolo.com)
[![React](https://img.shields.io/badge/React-19+-61DAFB?logo=react)](https://react.dev)
[![OR-Tools](https://img.shields.io/badge/OR--Tools-CVRP-orange)](https://developers.google.com/optimization)

StrongLogistics — це комплексна платформа для **керування логістикою**, **динамічного розподілу ресурсів** та **оптимізації маршрутів доставки** з використанням Google OR-Tools.

Система дозволяє:
- 📦 **Керувати точками доставки:** створювати, редагувати та видаляти точки на інтерактивній карті.
- 📋 **Керувати завданнями:** додавати нові завдання для водіїв, вказуючи необхідні ресурси та дедлайни.
- 🚀 **Оптимізувати маршрути:** автоматично розраховувати найвигідніші шляхи для автопарку з урахуванням ємності авто та пріоритетів доставки.
- 🗺 **Візуалізувати маршрути:** зручний вигляд для диспечера та окремий інтерфейс для водіїв.

---

## 🚀 Встановлення та локальний запуск

Для повноцінної роботи системи необхідно запустити як бекенд, так і фронтенд.

### 1. Запуск Backend (Сервер)

Бекенд написаний на Python (FastAPI).

```bash
cd backend
# Встановлення залежностей
pip install fastapi uvicorn ortools python-jose[cryptography] passlib[bcrypt] pydantic

# Запуск сервера
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Після цього API буде доступне за адресою: `http://localhost:8000` (Документація доступна за адресою `http://localhost:8000/docs`).

### 2. Запуск Frontend (Веб-інтерфейс)

Фронтенд написаний на React 19 + TypeScript (Vite).

```bash
cd frontend
# Встановлення пакетів
npm install

# Запуск сервера розробки
npm run dev
```
Додаток буде доступний у вашому браузері за адресою: `http://localhost:5174/` (або `5173`).

## 📖 Посібник користувача (Як користуватись)

### 🔑 1. Авторизація
Після відкриття додатку ви побачите екран входу. 
- **Логін:** `admin`
- **Пароль:** `stronglogistics2026`

*(Увага: прямий перехід на інші сторінки неможливий без успішної авторизації).*

### 🎛 2. Головне меню (Дашборд диспечера)
Після входу ви потрапляєте на панель диспечера (`/dashboard`). Зліва знаходиться навігаційне меню з трьома основними вкладками:

#### 📍 Вкладка "Точки"
Дозволяє управляти базою пунктів призначення.
- **Додати точку:** Натисніть кнопку `+ Додати точку`, введіть назву, координати (широта і довгота), об'єм потреби та рівень пріоритетності (Нормальний, Високий, Критичний). Точка миттєво з'явиться на карті.
- **Редагувати/Видалити:** Для кожної існуючої точки є відповідні кнопки швидких дій.

#### 📋 Вкладка "Завдання"
Слугує для формування списку конкретних нарядів на доставку.
- **Нове завдання:** Натисніть `+ Нове завдання`. Оберіть точку доставки з випадаючого списку. Введіть опис, тип ресурсу (наприклад, пальне, медикаменти), необхідну кількість та дедлайн.
- **Управління:** Створені завдання відображаються у списку. Їх можна відмітити як виконані або видалити.

#### ⚡ Вкладка "Стан" (Форс-мажори та скидання)
- Тут можна моделювати критичні ситуації. Оберіть точку на карті, задайте нову потребу та змініть її статус на "Критичний". Це дозволяє перевірити, як система перерахує маршрути.
- Кнопка **Скинути дані** поверне систему до початкового (заводського) стану з демо-даними.

### 🗺 3. Оптимізація маршрутів
На верхній панелі дашборду знаходиться головна кнопка **"Оптимізувати маршрути"**.
1. Натисніть її, коли усі точки та завдання вже додані.
2. Система (OR-Tools CVRP) автоматично розподілить завдання між складами та транспортними засобами, розрахує оптимальну черговість об'їзду та мінімізує відстань.
3. Процес займає кілька секунд. Ви побачите індикатор завантаження, а після завершення з'являться показники: загальна відстань та об'єм завантаження.

### 🚘 4. Вигляд водія
Біля кнопки оптимізації є кнопка **"Вигляд водія"** (Driver View).
Після успішної оптимізації натисніть на неї. Вона веде на окремий інтерфейс (`/driver`), що симулює планшет або телефон водія.
Тут відображається виключно:
- Ваша поточна геопозиція.
- Оптимальний маршрут, прокладений по реальних дорогах (від складу до всіх розподілених точок).
- Послідовність зупинок (1, 2, 3...) та навігаційна інструкція по найближчій точці.

## 📡 API Ендпоінти (Для розробників)

Додаток підтримує повний REST API:

| Метод  | Шлях                | Авт. | Опис |
|--------|---------------------|------|------|
| `POST` | `/api/login`        | ❌   | Отримання JWT токена (`{"username": "admin", "password": "stronglogistics2026"}`) |
| `GET`  | `/api/status`       | ❌   | Отримання списку усіх точок і складів |
| `POST` | `/api/points`       | ✅   | Додавання нової точки |
| `DELETE`| `/api/points/{id}` | ✅   | Видалення точки |
| `POST` | `/api/tasks`        | ✅   | Створення нового завдання |
| `POST` | `/api/allocate`     | ✅   | Запуск CVRP оптимізації маршрутування |
| `POST` | `/api/reset`        | ✅   | Скидання системи до демо-статусу |

Токен передається в заголовку: `Authorization: Bearer <token>`.

## 📐 Архітектура та Технології

- **Backend**: Python 3.10+, FastAPI, Google OR-Tools, Pydantic, python-jose, passlib
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS 4, react-leaflet, Leaflet, axios, lucide-react, React Router
- **Навігація/Карти**: CartoDB Dark tiles, OpenStreetMap OSRM (для трасування доріг)
- **Алгоритм**: CVRP (Capacitated Vehicle Routing Problem) із застосуванням `PATH_CHEAPEST_ARC` + `GUIDED_LOCAL_SEARCH`. Враховує пріоритетні штрафи та місткість (500 од. на транспортний засіб).
